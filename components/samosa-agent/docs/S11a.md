# S11a — approved checked copy and durable effect receipts

C02/C10/C11 subset. Agent owns immutable copy plans, exact approval, operation
intent/receipt and recovery. Host grants action_root/action_host_id; requests cannot
expand them. Public plan_create/get/approve/execute; one executor for every future
trigger. Copy <=8 regular files, each<=1MiB, relative source/destination within
one granted host/root. Source SHA versions and mechanical identities bind plans.

Record durable operation/item intent before filesystem work. Capture each source
through no-follow descriptors with version/identity/stability checks; stage native
bytes in an owner-only private directory on destination filesystem. Record staged
inode identity before atomic no-clobber publication. On worker death inspect exact
owned inode/receipts, never blindly retry. Previously committed destinations stay
intact. Completed exact retries return before root access. Approval binds immutable
plan revision1 and owner; model text/selection alone grants no authorization.

Acceptance: generated roots only, changed source, symlink/path escape/FIFO, foreign
existing destination, actual SIGKILL after publication but before final receipt,
public recovery recognizes own result and refuses changed foreign replacement;
owner/retry conflict and quota checks. Source and inference absent; shared executor
has no model policy. Native tests/sanitizers/independent builds Mac/Linux. No Python.

Preparatory bounded copy subset; move/undo/schedules and Source locator receipt
reconciliation remain required later assignments. No legacy action retirement
until all supported effect triggers and assembled quality gates qualify.
