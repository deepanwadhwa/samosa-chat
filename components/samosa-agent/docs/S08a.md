# S08a — parent-death ownership for native public helper calls

C11 subset: when the Agent process is killed during an active configured helper
call, its own helper/descendants terminate. Unrelated operations remain alive.
Agent public helper transport owns these processes; dependencies' private files
are never inspected. Sources/Inference daemon lifetime stays independent.

Included: native self-exec guardian mode launched with posix_spawn, inherited
private lifeline pipe, own target group/PID reservation and bounded timeout.
Guardian closes lifeline in target children, watches parent EOF independently of
stdout and reaps owned target after stopping descendants. No post-fork library
calls, Python, shell command interpolation or global kill flags.

Acceptance: existing bounded helper/deadline/descendant tests; actual worker
SIGKILL while helper+grandchild active, guardian/owned children exit; separate
unrelated helper continues. Public conversation reopens interrupted/last-good.
Native C tests/sanitizers and copied independent release. Full API cancellation,
transport/server fair scheduling and other C11 gates remain open.
