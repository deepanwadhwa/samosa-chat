# S15a — bounded concurrent durable Agent runs

C07/C08/C11 continuation after S14d's release gate. Agent owns admission,
conversation revisions, run state and recovery. Deliver up to eight independent
conversation runs in one state directory while preserving one active turn per
conversation and exact owner-scoped cancellation/status/retries. No waiting queue:
refuse capacity before user/run/event admission. Existing Sources/Inference own
their resource policies; Agent admission does not grant a model residency lease.

Include store.c, public conversations contract and standalone native C concurrency
runner/build targets. A short private admission gate protects recovery and
transactional slot/revision admission. Each admitted run holds its own kernel
worker lease through terminal publication; recovery checks that exact lease,
never marks unrelated live runs interrupted. Fixed histories/semantic/database
quotas remain bounded. The compact policy must refuse active conversations;
Eight live runs reserve three MiB each for their bounded terminal result and
derived state. Increase the semantic quota to32MiB and SQLite page quota to64MiB;
include all live reservations in admission and compaction quota checks. Keep
the existing256 run,512 event and per-conversation history limits. Per-run lease
files are derived only from validated64-hex run IDs and remain bounded by run
history. Recovery holds the short admission gate while checking exact leases.
it cannot change a running turn's revision/history. Snapshot get/status/events
remain available during work. Completion commits only the admitted revision.

Acceptance: two different conversations in one owner/state both reach active
provider work; cancel one, observe the other still running and uncancelled, then
release the healthy peer and verify its answer/history. Same conversation rejects
another admitted turn and compaction without appending history. Eight live runs
refuse a ninth before admission; SIGKILL of one recovers only that exact run and
frees capacity. Retry identity/foreign owner/stale revision and offline terminal
replay retain existing semantics. Shared request deadlines remain scoped. Run
existing store/control regressions and new regular/sanitizer tests on macOS and
native ARM64 Linux, then standalone release qualification. Focused commands will
be recorded with the implemented runner. Exclude service ingress, schedule
triggers, new policies/providers, App and legacy retirement; those subsequent
gates remain required by the full active rebuild.

Preparatory replacement concurrency: legacy gateway retirement awaits supported
assembled-product acceptance; no fallback to legacy is permitted here.
