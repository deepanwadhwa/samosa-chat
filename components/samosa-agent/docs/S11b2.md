# S11b2 — approved checked move and inverse move

C02/C10/C11 subset. Agent owns immutable move plans, approvals, intents and
historical receipts in its existing actions database. Deliver a bounded move of
one to eight host-granted files and a separately approved inverse through the
same plan_execute entry point, kernel lease, quotas and retry handling.

Included: actions.c/h, public actions contract and native action acceptance tests.
Use native atomic no-replace rename for same-filesystem moves; refuse unsupported
cross-device effects before changing paths. Bind source content, metadata and
inode, root and both parent directories. Record intent before capture, verify an
owner-private quarantined source before publishing at the new name, retain an
identity anchor, and record committed move receipts. Refuse foreign or changed
files. Interrupted effects require exact inode reconciliation without blind
replay; an explicit new operation resumes verified stages. The original source
pathname is absent only after a verified move; foreign later files are preserved.
Inverse plans bind committed moved inodes and require separate exact approval.

Acceptance: approval refusal without effects; successful move and inverse;
existing destination, changed source, changed parent/root and path escape refusal;
actual SIGKILL after capture and after destination publication; exact retry,
reconciliation and foreign later names remain intact. Native Mac/Linux tests,
sanitisers and independent public Source readback of moved evidence. No Python.
Focused commands will be recorded when the runner exists. Complete only after
all these cases pass. This is preparatory for C10; schedules, organization, live
Source receipt reconciliation, App and broad quality/retirement gates remain open.
Implementation begins after S11b1 qualification completes.

Native focused runner: `make build/test-move && ./build/test-move` (510 checks
currently). Full `make test sanitize release`; external public interaction:
`make test-actions-interaction SOURCES_EXECUTABLE=/external/samosa-sources` (120
checks for finding/copy/undo/move/inverse/Source readback). Linux distinct-filesystem
