# S05 — native durable document conversations

C06/C07/C08 subsets. Agent owns SQLite conversations/messages/runs/events,
selected scope and copied literal admitted evidence. Inference continuation is a
cache, not semantic authority. No Python. Existing question policy remains the
one evidence validation/prompt/budget path: add replay entry point, not second
answer implementation. Follow-up from stored evidence performs zero Source calls.

Host config --state private dir and --owner; requests cannot choose either.
Public create/get/events/submit/get_run; conversation/op IDs/revision bound to
owner. Submit reserves a durable running run plus user message/event before work.
Exact normalized operation retry resolves before dependency calls; changed request
with same ID refuses. One host work lock, zero queued for this CLI subset; recovery
only under that lock, never interrupts a live peer. Interrupted work never replays
and never invents assistant output. Commit assistant/result/scope/evidence in one
transaction. Failed or interrupted new selection preserves last-good admitted
scope/evidence together; selection intent remains in the failed run.

Public submit: conversation_id, expected_revision, operation_id, question;
optional source_id/version plus exactly one byte/page range. Initial selection
required; absent selector reuses last-good pinned scope/evidence. Semantic history
is typed messages, with failed/run statuses; never promotes assistant prose to
literal source evidence. New selected source requests an explicit bounded read.

Limits before accepting work:64 conversations/256 retained runs/512 messages per
conversation/512 events, <=2KiB question,1MiB result,8MiB total retained results,
8MiB total retained semantic data,16MiB SQLite database, bounded recovery/events(max100), no silent eviction. Retain
space for terminal results/errors before accepting a run; admission fails closed
when exhausted. Trace model_request is headless diagnostics, not persisted twice.
SQLite snapshots are owned metadata; no Source/Inference private tables/files.

Acceptance: separate native CLI create/read/submit/reopen from empty client;
pinned followup after original file removal and with Source command unavailable,
completed exact retry with Inference unavailable; changed parameters/foreign owner/
stale revisions/concurrent work refuse; actual reserved process kill/reopen marks
interrupted; ordered events align with messages; failed new selector preserves
old admitted scope/evidence. Native C tests/sanitizers/release and actual provider
workflow; clean standalone copies. Broader event streaming/service/cancel/session
and resource gates open until their later focused qualification. Preparatory;
legacy conversation paths retire only after all relevant gates pass.

Crash injection: C test build alone defines SAMOSA_AGENT_TEST_FAULTS. Its reserved
commit barrier writes an owned marker and waits; parent SIGKILLs that real process,
then reopens via the public API. Production binary has no test barrier/environment
hook. This tests durable run/event recovery before child dependency creation;
mid-reader/native root-crash child teardown remains a separate open C11 gate.
