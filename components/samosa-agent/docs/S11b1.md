# S11b1 — approved inverse plan and checked copy undo

C02/C10/C11 subset. Agent owns undo plans/approval/intent/receipt. `undo_plan_create`
binds an original owner-bound copy plan's committed publication inodes/versions to
an immutable inverse plan. It requires its own exact approval, then uses the same
plan_execute entry point/admission/lease/recovery as copying. Original receipt
history is retained; undo cannot delete a foreign replacement or modified copy.

Included: native atomic no-replace rename primitive on supported Mac/Linux,
owner-private quarantine of the destination, capture verification before unlink,
no-clobber restoration for a raced foreign capture and durable prepared/undone
receipts. Record intent and expected inode before effects. SIGKILL recovery inspects
quarantine/target and never blindly deletes/replays. Source originals remain intact.
No new model policy or second scheduler/executor. Bounds use S11a quotas.
Private hard-link identity anchors prevent inode reuse; state/destination must be
on the same filesystem, otherwise publication refuses cross_device_anchor.
Historical anchors persist within the fixed item quota. Original receipts expose
reversed=true after a committed inverse without erasing publication history.

Acceptance: explicit inverse approval, exact own copy removed/original preserved,
foreign replacement and same-inode modification refused; actual worker SIGKILL
between quarantine and final unlink, historical receipts retained; raced foreign
capture restored with no overwrite. Native tests/sanitizers/copied releases Mac/
Linux and public Sources read/copy/undo interaction. No Python.
Unknown quarantines remain explicitly unreconciled and do not block unrelated
approved plans. A native crash fixture temporarily removes the quarantine name,
checks an unrelated copy, restores the known stage and explicitly resumes undo.

Focused runner: `make build/test-undo && ./build/test-undo` (477 checks).
Full checks: `make test sanitize release`; public interaction:
`make test-actions-interaction SOURCES_EXECUTABLE=/external/samosa-sources`.
Linux distinct-filesystem fixture: `make test-cross-device` (requires /dev/shm on
a different filesystem from /tmp). Final results live in the main checkpoint.

S11b2 adds checked move/undo-move using the same kernel primitive/executor after
this subset qualifies. Schedules, organization, Source receipt reconciliation and
assembled product retirement remain required. S11b1 is preparatory for full C10.
