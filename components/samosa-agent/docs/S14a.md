# S14a — durable run cancellation

C07/C11 preparatory continuation owned by Agent. Deliver cancel_run for a
host-authenticated owner's durable submit/submit_chat run. Requests select exactly
one operation_id or run_id; no request selects owner or private state. A durable
cancel flag remains observable while the worker owns its work lease. The worker
polls that run through scoped callback configuration, closes only its helper
lifeline and commits cancelled without an assistant message. Last-good evidence,
continuation and successful history remain unchanged. Completion/cancel races
are serialized by the final SQLite transaction; committed success remains success.
Dead-worker recovery uses the existing exclusive work-lease proof. Exact retries
return saved terminal state offline. No global service cancellation slot.

Included: scoped native command transport cancellation, durable control records,
public run status/cancellation and native peer/refusal/race/recovery fixtures.
Excluded from this subgate: multi-run worker admission, explicit cross-owner
parent/deadline envelopes, long-lived dependency control propagation, real-model
active cancellation and App. These remain required follow-on gates. Existing
single work lease remains until per-conversation worker concurrency is qualified.
Preparatory work; no legacy path can retire based on this cancellation subset.
Acceptance command: make test-run-cancel sanitize-run-cancel,
then existing Agent tests and independent macOS/native Linux qualification.

Implementation: run_controls is Agent-private and keyed by host owner/operation;
get_run and cancel_run expose only generic status/flag fields. The transport adds
command_call_controlled while existing unscoped public helper callers retain the
same implementation through command_call. Scoped submit configuration carries a
callback/context for only that run. The final cancellation observation and
semantic publication share the terminal SQLite transaction. No assistant or
last-good context update is made for cancelled work. Kernel work-lease recovery
records cancelled for a dead already-cancelled worker, otherwise interrupted.

Native fixtures run two independent same-owner/same-operation workers. They prove
wrong-owner/unknown/ambiguous request refusal, exact run-ID cancellation, actual
helper/descendant/guardian disappearance, a live untouched peer, unchanged prior
scope/message history, surviving subsequent turn, offline exact retry, late
success preservation and actual reserved-worker SIGKILL after durable cancel.
Counts include poll/clock assertions and differ between normal/sanitized hosts.
Independent build/sanitizer/release evidence is recorded in the main checkpoint.
